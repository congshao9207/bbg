优化方案
1. 预编译正则表达式
将 label_config.py 中的正则表达式字符串预编译为正则对象，避免重复编译开销。

2. 向量化字符串操作
将 apply(lambda x: abs(x)) 改为 abs() 或 np.abs()
将日期提取操作改为向量化：df['year'] = df['trans_time'].dt.year
3. 批量 DataFrame 操作
将多个单独的 loc 操作合并为批量操作，减少 DataFrame 复制次数。

4. 优化循环逻辑
将还款日期前一周标签的计算改为向量化操作
使用 groupby + transform 替代循环设置排序标签
5. 缓存中间结果
缓存常用的字符串拼接结果
预先计算并存储常用的过滤条件
6. 使用更高效的数据结构
对于频繁的成员检查，使用 set 而非 list
对于关联关系字典的查找，优化键值匹配
7. 并行处理
对于独立的标签计算（如不同类型的标签），可以考虑使用多进程并行处理。

8. 减少内存占用
及时删除不再需要的临时列
使用适当的数据类型（如 category 类型存储重复字符串）
